`main.ts` writes one confession to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR`,
fallback `/output`), prints it, and self-checks the gate: 1–88 characters,
one to five words, a single line, not only whitespace.

Run: `node main.ts`
